# Hexagonal-Battleship
A variation of battleship with a hexagonal board and different ships


I made this design because I love playing Battleship and I thought it would be great to make my own version of it with variations that I came up with.

I came up with this project while looking through a cabinet in my house for random objects. I saw the battleship and thought it would be a good idea, since it is not a classic board game, which would have been too easy. I started with a square version and switched to a hexagon after some time. I made the ships unique for fun, and I wanted to make it more different. The pegs are longer so that they are easier to hold.
